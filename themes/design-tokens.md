### 1.5 ANSI 色映射

| ANSI Code | 名称 | 暗黑模式 | 明亮模式 |
|-----------|------|----------|----------|
| 30 | 黑 | `#A0A0A0` (提亮) | `#000000` |
| 31 | 红 | `#FF6060` | `#FF0000` |
| 32 | 绿 | `#60FF60` | `#008000` |
| 33 | 棕→黄 | `#FFD700` | `#A52A2A` |
| 34 | 蓝 | `#569CD6` | `#0000FF` |
| 35 | 紫 | `#C586C0` | `#800080` |
| 36 | 青 | `#4EC9B0` | `#008080` |
| 37 | 灰 | `#C0C0C0` | `#808080` |
| 90 | 亮黑 | `#808080` | `#808080` |
| 91-96 | 亮色 | 亮度提升 20-30% | 同 31-36 |
| 97 | 亮白 | `#F0F0F0` | `#C8C8C8` |

> ⚠ **注意**：暗黑模式下 ANSI 黑(30) 被提亮至 `#A0A0A0`，棕(33) 被映射为金黄 `#FFD700`，这是暗底可读性的必要调整。但暗黑/明亮模式下同 ANSI 色号的实际颜色差异显著，可能在双主题混合使用场景造成困惑。

## 2. 字体系统

### 2.1 字体家族

| 用途 | 字体 | 使用场景 |
|------|------|----------|
| **界面标签** | Microsoft YaHei | 按钮、标签、复选框、GroupBox 标题 |
| **代码/数据** | Consolas | 收发数据区、串口参数下拉框、路径输入、统计 |
| **大标题** | Microsoft YaHei Bold | GroupBox 标题(QSS) |
| **菜单** | Microsoft YaHei | 右键菜单 |

### 2.2 字号层级

| 层级 | 大小 | 用途 | 暗黑 QSS 字体粗度 |
|------|------|------|-------------------|
| `--font-base` | **8pt** | 按钮文字、标签、复选框、下拉框、表格 | 无（默认 Normal） |
| `--font-md` | **9pt** | GroupBox 标题（粗体）、菜单 | `font-weight: bold`（GroupBox）、无（其它） |
| `--font-lg` | **10pt** | 部分按钮/标签（少数） | — |
| `--font-data` | **11pt** | 接收区数据正文 | `QFont.Normal` |
| `--font-xl` | **12pt** | 大号按钮（极少数） | — |

> **问题**：仅 5 个字号层级，8pt 是界面主体。8pt 在 96 DPI 下约 10.7px，在高 DPI 屏幕偏小。接收区 11pt 为数据阅读而设。
>
> ⚠ **发现**：9pt Bold 仅 GroupBox 标题使用，其余 9pt 为常规字重。暗黑 QSS 中 `QGroupBox` 设了 `font-weight: bold`，明亮 QSS 中未设 —— 导致双主题切换时 GroupBox 标题粗度一致（因 QSS 覆盖），但代码中 `setFont(QFont("Microsoft YaHei", 9, QFont.Bold))` 做了双重保障，无问题。

## 3. 边框与圆角

| 令牌 | 值 | 使用位置 |
|------|-----|---------|
| `--radius-sm` | **3px** | 复选框指示器、进度条、滑块轨道/手柄 |
| `--radius-md` | **4px** | 输入框(QTextEdit/QLineEdit)、下拉框、按钮、微调框、表格、进度条、滑块 |
| `--radius-lg` | **6px** | GroupBox、滚动条（整体）、状态栏（无） |
| `--radius-xl` | **7px** | 滑块手柄（圆形） |
| `--border-width` | **1px** | 全局统一 |

> **问题**：`--radius-xl` 仅 7px 且仅用于滑块手柄。实际滑块手柄尺寸 14×14，7px 正好是圆角 50%，应标注为 `--radius-round` 而非递增 1px。

## 4. 间距系统

### 4.1 QSS 间距抽取（已规范化至 4px 网格）

| 属性 | 原值 | 现值（网格对齐） | 使用位置 |
|------|------|------------------|---------|
| `padding: 0` | 0px | 0px | ScrollBar add-line/sub-line |
| `padding: 0 8px` | 0 6px | **0 8px** | GroupBox::title |
| `padding: 4px 4px` | 2px 4px | **4px 4px** | QSpinBox |
| `padding: 4px 8px` | 2px 6px | **4px 8px** | QComboBox |
| `padding: 4px` | 4px | 4px | QPushButton、QHeaderView::section |
| `padding: 4px 0` | 4px 0 | 4px 0 | QMenu |
| `padding: 8px 28px 8px 16px` | 6px 28px 6px 16px | **8px 28px 8px 16px** | QMenu::item |
| `margin-top: 12px` | 12px | 12px | QGroupBox |
| `padding-top: 16px` | 14px | **16px** | QGroupBox 内容区 |
| `left: 12px` | 12px | 12px | QGroupBox::title |
| `margin: 0` | 0px | 0px | ScrollBar |
| `margin: 4px 8px` | 3px 8px | **4px 8px** | QMenu::separator |
| `margin-right: 8px` | 6px | **8px** | QComboBox::down-arrow |
| `margin: -4px 0` | -4px 0 | -4px 0 | QSlider::handle |
| `spacing: 8px` | 8px | 8px | QCheckBox（文本与指示器间距） |

> ✅ **2026-06-03 已规范化**：所有非 4px 倍数的间距值已统一。仅保留下拉箭头三角形尺寸（`border-left/right: 5px`、`border-top: 6px`）未改，因其定义三角形形状而非间距。

### 4.2 布局间距

布局层面（代码中的 `QHBoxLayout` / `QVBoxLayout` / `QGroupBox`）：

| 位置 | 间距方式 | 值 |
|------|----------|-----|
| 串口参数行 | `QHBoxLayout` + `setFont` | 紧密排列，无额外 spacing |
| 复选框行 | `QHBoxLayout` | 控件间 ~6px |
| 接收/发送 GroupBox | `QVBoxLayout` + GroupBox margin | margin-top 12px |
| 右键菜单 | QSS padding | 6px 28px 6px 16px（item） |
| 滑块宽度 | `setMinimumWidth(150)` | 150px |

> ⚠ **发现**：当前间距系统未遵循统一网格。常见值为 2/3/4/6/8/12/14/16/28px，无法被 4px 网格整除的值：2px、3px、6px、14px。建议统一到 4px 网格（2→4, 3→4, 6→8, 14→16）。

### 7.3 发现的问题与建议

#### 🔴 问题 1：禁用文本对比度不足
- **影响**：两主题均不满足 WCAG AA
- **建议**：暗黑 `#606060` → `#808080`，明亮 `#AAAAAA` → `#888888`

- **影响**：`#0078D4` 在 `#F5F5F5` 背景上不够明显
- **建议**：`#0078D4` → `#005A9E`（可得 4.7:1），或保持原色加 2px 外发光

- **当前**：`#A0A0A0`，在暗灰背景中偏深

#### 🟡 问题 4：两主题间 ANSI 色映射差异大
- **影响**：同 ANSI 色码在切换主题后颜色突变（如棕色→金黄）
- **建议**：记录为已知特性（暗底必有此调整），文档中标注

#### 🟢 问题 5：间距系统未网格化
- **发现**：存在 2/3/6/14px 等非 4px 倍数值
- **建议**：纳入下轮重构计划统一为 4px 网格

#### 🟢 问题 6：字号层级偏少
- **当前**：8/9/10/11/12pt
- **建议**：增加 7pt（辅助信息）和 14pt（数据大标题）以丰富层级
